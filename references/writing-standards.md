# 写作与结构标准

用于形成正文、选定结构和校准文风；编辑也用它检验用户已有材料能长成什么。活稿、当前稿和定稿共用本标准；编辑每次检查只针对新增或受影响的段落，定稿再检查整篇。编辑的检查不停留在评价上：说得出问题，就要顺手给出改法。不把这份文件变成前台问卷或每段必填表，也不用机械评分表代替判断。句子、段落、物件复用、幽默位置和原创迁移的具体规则见[文风生长与迁移标准](style-growth.md)。

## 先判断观众怎样往前理解

每段实质文字写成或改完，编辑当场检验三件事：这一语义段开始时观众知道什么；结束时多理解了什么；哪项材料或解释带来变化。变化可以是知道一个事实、看清关系、理解约束、修正判断，也可以是感受到此前未理解的代价。

答不出来就是缺口。编辑按具体问题补材料、补因果步骤、调整位置、合并重复或删除，并直接说明这一步改了什么、为什么。不是每句都要新知识；铺垫、复述、停顿和幽默可以完成必要任务，不把稿件压成知识点串讲。

入口须建立具体解释任务，但不强制反常识或故事开场。真实困难、关键区别、昂贵选择与待解释判断都可以成立。开头入口的选择应按[文风生长与迁移标准](style-growth.md)中的四类入口判断：宏观引申、反常结果、历史回望或具体场景。答案可以早说，悬念可以是“为何成立、如何发生、何时失效”。不能为了悬念藏起后文必需的前提，也不能把所有题材机械写成场面先行。

## 按题目和材料选择结构

下列是可组合的选择，不是顺序流程。平时在后台选定；选题尚未成立时不进入正式结构。

| 结构路线 | 何时适用 | 需要防止什么 |
|---|---|---|
| 问题与反问 | 有一个解释，且存在足以挑战它的疑问 | 弱反方陪衬、回避真正反例 |
| 排除常见解释 | 几种熟悉答案解释不全，需要建立更好的比较尺度 | 未列全选项却宣称穷尽，只否定不建新解释 |
| 资金或货物流动 | 关键是付款、垫付、结算、履约或风险转移 | 漏掉关键环节却声称闭环 |
| 人物关系变化 | 行动改变依赖、利益和选择空间 | 简历罗列、全知心理、以性格包办原因 |
| 优势转为约束 | 原来的解决办法在条件变化后产生风险 | 把后来结果写成从一开始就注定 |
| 多方相互影响 | 各方行动共同维持某种结果 | 罗列“多元原因”，不解释先后、放大与纠正机制 |
| 空间或代际导览 | 地点或代际提供稳定坐标，并确实改变关系 | 景点或人物百科，与核心问题脱节 |

作为编辑，这张表由你主动使用，不由用户来选。看完材料先定一条最合适的路线，并说出理由：材料里的哪个环节、哪种关系、哪一步变化决定了走这条路线；理由必须指向材料，不能只说“这样更好看”。用户已经定了路线而你认为不合适时，明说不合适：指出按这条路走会在哪里撑不住、代价是什么、你替代的那条路线是什么、为什么它更合材料。不要为了顺着用户而默默按原路线写完；也不要明知有更合适的路线却不说。路线选定后一旦发现材料不支持，当场换掉并讲清换线的理由，不把旧提纲硬撑到底。

临时想到的连接句同样当场检验一次；经不起这一步的句子，当场删掉，并说明删掉之后哪一段的承重变弱、需要用什么补回来。

连接可以来自后果、反问、条件变化、比较需要或时间推进，不机械使用“那么问题来了”。并列比较有时可以交换次序，不强求所有段落都不可移动。后续认识变化时允许换结构，不为了保存旧提纲扭曲材料。这条灵活性用来回应真实的认识变化，不用来回避必须做出的关键判断，也不用来替段落整齐牺牲材料的承重。

## 材料要完成叙述或解释任务

故事重点检查行动、约束和后果如何改变局面，不只检查人物、时间、地点是否齐全。一个物件、账本或关系可以反复出现，每次揭示不同作用，减轻观众重建背景的负担。

事实案例、用户陈述、假设与类比使用不同的证据口吻。没有来源的现场动作、对话和内心不能用来增强画面感。具体事实及论证检查按[研究与事实边界](research-protocol.md)执行，不能因为参照作品这样写就照搬其确定性。材料撑不住时，当场说明缺什么：缺一个来源、缺一步因果，还是缺一个能观察到动作的现场。

## 文风与叙述

叙述模式沿用项目约束，具体转换按[编辑运行协议](editorial-protocol.md)执行。当前用户默认外部公共议题讲述：亲历提供材料，作者人格通过选材、比较、判断、质疑和评论形成。

口语化首先是理解顺序。让主语和动作清楚，术语出现时观众知道它在解释什么；长句承载必要条件，短句收住关键区别，不限制统一句长。评论贴住材料，讽刺可以揭示落差，不用辱骂群体代替分析。比喻服务于同一关系，避免频繁更换意象导致解释失焦。

结尾兑现开头的解释任务，并保留正文建立的条件。可以回到同一事件或物件，让其意义发生变化；也可以给出适用于新案例的判断方法，不强求宏大升华。

## 六项质量导航如何落实

沿用运行协议的六项公式，不将其当作数学评分或固定篇章结构。

| 观察维度 | 发现不足时的修改方向 |
|---|---|
| 值得追的问题 | 缩小到可观察的困难、区别或落差，说明本篇能解释什么 |
| 清楚的认知坡道 | 补必要前提、调整顺序，减少同时引入的陌生对象 |
| 具体有力的材料 | 补行动、约束、后果和来源，删掉仅装饰气氛的细节 |
| 可复述的解释模型 | 展开因果中间步骤与比较条件，说明何时不适用 |
| 鲜明可信的人格 | 让有根据的判断贴住材料，保留分歧和取舍，不靠自夸与口头禅 |
| 经得起核查的边界 | 核查承重主张，统一口径，收窄超过依据的结论 |

编辑用这张表定位最承重的那一项缺口：哪一项接近缺失，就会限制整体，例如关键材料撑不住时，先把人格与模型两项放下。一次只推动一到两项，给出改法和改后文字，让用户在这一到两项上否决或接受；不要一次列出六项问题，把用户淹没在清单里。其余不足先记在编辑意见台账，等当前这一两项落定后再提。判断要落到具体修改动作上：说得出改的是哪一句、哪一段。

听起来清楚与证据成立分别判断：表达有效不证明结论真实，核查无误也不证明文章有吸引力。没有后台数据时，吸引力判断是文本分析，不是经过验证的留存效果。编辑要能指出这条判断落在哪一句、哪项材料上；说不出来，就说明还没读到真正的问题。不要为了显得严格给优秀段落硬凑缺点。

## 两个微型示例

以下为原创写法演示，不是已核新闻或对标作者原句，也不是所有稿件的固定模板。

“AI乱象源于时代局限和认知错配”只列出抽象原因。可以试写：“软件能够开播，与客户能够靠它赚钱，中间隔着流量、成交和履约。现场演示证明了哪一步，客户付钱时期待的又是哪一步？”后文须用真实材料检验这些环节，不能预设存在欺骗。

“信用迁移造成预期膨胀”可以展开为：“按照这名员工的描述，销售带客户参观集团展厅时，会把集团资源与AI项目联系起来。展厅展示了集团过去做成过什么；眼前项目能交付什么，还需要另外验证。”这里保留来源，写出可观察动作与关键区别，不替所有客户断言心理。

这两个示例展示的是编辑改稿时的判断方式：先指出原句的问题——抽象、无承重、拿一个概念代替实际发生的环节；再给出可观察的动作与关键区别；最后守住边界，说明不能替所有客户断言心理。示例只说明这个机制，不是固定模板：换一段材料，动作、区别和边界都要重新从材料里找。

## 定稿前与实际使用

活稿允许缺段和竞争解释，但已有正文就应面向陌生观众，工作注分开。定稿优先检查主线、承重材料和连接，再朗读修整重复、歧义和节奏；不以完稿为由突然更换叙述方式。

需要反馈时，编辑指定怎么测：让陌生读者复述问题、关键关系、没跟上的位置和结论条件；发布后结合留存、受众与声音画面判断，不只归因于句式。独立成稿评审仍由评审Skill承担，编辑环节用这份文件和编辑判断就够，不重复完整评分流程。

## 研究依据与可移植性

本标准源于当前项目2026-09-09的文字研究：55篇可用全文及4篇缺损转载全行研读，不代表完整视听、全部事实核查或受限节目全部读取。它是可修正的创作方法，不代表对标作者唯一正确的写法。编辑版在同一批材料上增加了三项处理：由编辑主动选定结构路线并说明理由；用六项质量导航定位最承重的一项缺口，一次只推进一到两项；改稿时保留用户的判断与声音，并区分改稿、核查、独立评审三件事。这些是编辑做法上的调整，不改变上述方法的来源与限度。

需要具体依据时，如果用户当前项目中存在 `对标研究/正确君与新闻大写-文风结构/全量文字研读索引与完成状态.md`，可按主题进入对应笔记；综合解释见同目录 `全量文字研究-文案观点故事论证与文风.md`，只读与当前问题相关的材料。项目里不存在这些笔记时，本文件仍可独立执行；不得声称已读取缺失笔记，也不依赖原电脑的绝对路径。无需把整套逐字材料复制到公开Skill包。
