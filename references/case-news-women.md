# 《新闻大写》“共产党的女人们”：路线与25拍工作重建

## 案例身份与证据边界

用户称本例为“共产党的女人们”，对应视频《吴仪裸退死磕薄熙来，孙春兰替封城背锅，中国女人的官场有多残酷？》。公开入口：[完整视频](https://www.youtube.com/watch?v=_wGBPAYMA-I)、[作者示例帖](https://x.com/goshenggo/status/2118009324928970901)、[方法说明帖](https://x.com/goshenggo/status/2118000422858453353)。

本文件是此前案例研究的原创结构分析摘编，没有收录整篇字幕、他人完整文案、原始视频或私人聊天。此前研究记录的观察范围是43:12全片的1253条中文字幕、114个选点画面及约68秒作者示例；没有完整人工试听音轨或逐帧核准，情绪方向是预期作用，不是观众实测结果。

作者公开说一期“大概25个左右”，没有取得其原始Beat Sheet。下表按25拍重建，是一种可用工作假设，不是唯一切法，也不能证明作者真实制作顺序。简介25个章节不等于25拍；作者示例约68秒与成片开头约53秒并非同一剪辑版本。

**本例中人物事件、讣告、数字、内幕和因果均以“节目怎样叙述”为分析对象，不作事实背书。开场讣告、日期、席位口径及后文私下交易等并未完成独立核验。任何新作品重用相关事实，都必须重新核查。表内“观众获得”表示节目试图建立的理解，不代表证据已证明该理解。**

## 怎么读

本例主要方法：先建立一种解释与预测，再展示它解释不了的情况，转入下一层问题；每层都交付部分答案。适合材料真的存在这种张力的选题，不要求其他项目都用排除法、政治叙事或持续反转。

## 六个重点拍的详细卡片

**B01｜00:00–00:53｜三份讣告与一排男性席位**

写前任务：借刘延东的新闻，把个人离世扩大为一个群体位置问题；先让观众看到最高层的空缺。

观众变化：这可能是一期人物悼念或官场新闻。 → 几位先行者相继退场，最高层女性位置并未继续推进。

拍内动作：刘讣告→最高职务→常委女性为零→18个月三位先行者退场→22把椅子全男。

信息回报与情绪：节目并列三位女性先行者的讣告与全男性政治局，以过去有人突破对照当下空缺。 严肃的新闻感，转为反差与不解；冲击来自排列关系。

材料与画面：完整版开头用殡仪馆、讣告页及黄色标注、常委入场等新闻影像；帖子示例则大量用档案纸、台阶、电梯、人形。 承重材料应是：节目所用讣告、职务与会议名单；均需独立核新闻真实性及统计口径。

交棒：这只是顶层的偶然空缺，还是整个晋升通道的问题？

边界判断：中高：功能与帖子示例高度对应，但帖子68.3秒不等于成片53.66秒，且视觉不同。 论证边界：开场新闻、死亡日期和22席为节目陈述，本研究不替其真实性背书；常委/政治局必须分开。

**B06｜07:50–09:09｜把胜算抬到最高，再让名单落空**

写前任务：让观众先用常见官场解释预测结果，再拿实际名单打破这个预测。

观众变化：她应当接近晋升。 → 既有优势仍解释不了未入常委，需要寻找遗漏条件。

拍内动作：四方认可→引潜规则→预测政协主席/常委→红毯七男→同辈对照→提出主谜。

信息回报与情绪：书中人事规则、当时晋升预期、2012年七人名单和其后的分工。 胜算接近饱和→明显落差→解释欲被放大。

材料与画面：常委席位图及名单、入场影像、台阶或门的母题。 承重材料应是：《红色轮盘》说法、当年媒体预测、公开任职名单。

交棒：是性格不够强，还是资历没凑齐？

边界判断：高：7:50论预期，8:30名单反转，9:05落主问。 论证边界：书中经验规则不是充分条件；“几乎所有观察家”需样本支持。落选不能独立证明唯一原因。

**B07｜09:09–11:03｜把个人缺点，翻成机会分配问题**

写前任务：认真摆出两种现成解释，再翻转资历的因果方向，预埋吴仪和孙春兰两个后续检验。

观众变化：可能只是刘本人太软、没地方主政经验。 → 缺资历也可能是被安排的结果；问题转到组织如何分配岗位。

拍内动作：性格/资历两解释→追问资历从何而来→男同事去地方→吴孙反例→机器座位表→回溯制度史。

信息回报与情绪：同代男性团干部获地方历练的对照；吴仪、孙春兰这两个不同类型的案例。 从接受解释到发现解释不够；愤懑来自因果翻转。

材料与画面：媒体文章、履历对照、人物与岗位关系；画面服务“谁被送去哪里”。 承重材料应是：刘与男性同代干部履历、媒体评价、吴仪和孙春兰的职位。

交棒：这种座位表从什么时候开始形成？

边界判断：高：连续完成排除旧解释、提出新方向、倒回历史的转轴。 论证边界：吴孙案例削弱两个简单解释，却没有排尽年龄、任期、职位配置、派系等其他解释。

**B14｜21:27–23:03｜第一场改革：让观众亲手划掉候选人**

写前任务：先承认差额选举的进步意图，再让观众站到投票者位置，理解资源不平等怎样影响竞争。

观众变化：竞争机制理应更公平。 → 程序竞争叠加原有资源差异，可能使弱资源群体更容易落选。

拍内动作：清零问题→两改革预告→差额制度→请观众决定划谁→财政/组织/公安难得罪→软部门更易被划→人数落点。

信息回报与情绪：差额规则、资源岗位差异、节目给出的女性中央委员人数变化。 期待改善→参与判断→发现后果；观众自己完成关键一步。

材料与画面：候选与划票文字、人物/职位对照、档案影像。 承重材料应是：十三大党章及选举规定、委员名单与地方数据；资源机制需要研究支撑。

交棒：这是一张选票的影响；家庭劳动和工作支持又怎样变化？

边界判断：高：清楚单一机制；观众选择题是拍内的主要理解重音。 论证边界：中央委员会差额与政治局产生程序不能混为一谈；相关人数变化不足以单独证明具体官员退场原因。

**B20｜31:20–32:18｜白雪公主短剧：被叫醒是去救灾**

写前任务：在机制长段与吴孙案例之间换气，先用荒诞情境预演“被需要是去接危机”。

观众变化：刚形成完整四筛模型，开始问突破后的代价。 → 对玻璃悬崖有一个先于术语的直觉。

拍内动作：过场→王子唤醒公主的童话预期→扇醒/反转→洪水疫情缺女背锅→余味→第四章。

信息回报与情绪：没有新增历史事实；把“被提拔/被叫醒”重新解释成接下灾难。 轻松、恶趣味、突转苦涩；笑点本身带出下一段主题。

材料与画面：约31:19后含过场，31:44起短剧对白，32:18回正文；白雪公主卡通风格。 承重材料应是：自编短剧；不是现实案例的证据。

交棒：这种危机时才获重用的情形，有什么概念和现实样本？

边界判断：中高：短剧独立；31:20边界按前句结束分配，非首句对白时间。 论证边界：夸张的“故意找女背锅”不能直接替代玻璃悬崖概念的完整定义。

**B25｜42:09–43:12｜把四道筛子，压成一个人的一生**

写前任务：停止加研究，把既有机制转成当代女性的合成职业经历，回收考卷、后院、悬崖和牌桌。

观众变化：观众掌握许多历史人物和制度机制。 → 记住一个有情感重量的命题：能进门，与能决定规则，是两回事。

拍内动作：长安街女孩→53%回开场→考卷进门不上桌→公文与酒局→产假/年龄/流言/退出→后院/悬崖/公文三重回收→牌桌→告别。

信息回报与情绪：没有新的主要机制；将前文材料重新整合成可以复述的总理解。 从统计尺度推近个人生活，降低新信息密度，让意义和情绪集中落下。

材料与画面：长安街实拍、孕肚等象征、红色圆桌片尾；高低层级与门/桌的视觉回收。 承重材料应是：前面用过的统计与机制；女孩是合成人物描写，非指认得到的采访对象。

交棒：全片结束；留下可复述的命题，而不是再开一组知识点。

边界判断：高：明确现实化结尾；最后告别与尾音计入本拍至43:12。 论证边界：合成人生有感染力，但不能当每位女干部的必经轨迹；结尾的确定表达仍要受前文证据约束。

## 公开示例如何校准一拍

作者示例包含讣告、职务标注、台阶、电梯、年份、人物、文件与人形等视觉动作。其主任务可重建为：个人新闻 → 女性最高位置 → 群体尺度扩大 → 当下席位对照 → 打开全片问题。

多组画面服务一个主要叙事动作，因此不能每换图就拆拍。示例和成片不同也说明，拍先定义任务，视觉方案可以变化；不能从作者使用scene的方式推导所有制作都必须一拍一镜。

## 从这些安排迁移什么

|安排|判断与作用|迁移边界|
|---|---|---|
|刘延东优势逐步叠加后落空|观众实际形成预测，结果才产生解释需求|优势不构成充分条件，落空不能单独证明唯一原因|
|从缺资历追问岗位机会|改变解释层次，后续材料因此有进入理由|必须有岗位分配证据，不能只靠反问完成因果证明|
|吴仪、孙春兰前后两次出现|先检验简单解释，后回答穿过筛子以后会怎样|同材料分次承担不同任务，不能重复讲同一结论|
|豆包与公主两段短剧|换气并过桥，后一段先建立危机任务的直觉|模拟情境不是史实，笑点不能替代论证|
|结尾合成一个女孩的生涯|回收既有机制和母题，整合意义与情绪|明确合成情境，不冒充真实个案或证明所有人遭遇相同|

## 转为写前指令

成片分析问“这里为什么有效”，写前改问：观众现在怎么想 → 希望改变什么 → 哪段材料足以支持 → 怎样排序 → 落在哪里 → 为什么继续。

本例展示预期、落差与解释层次；香农篇展示演示、尝试和理解步骤。按题材选择，不把其中一种方法当唯一结构。

## 证据不能被叙事力量替代

极端优势个案足以提出问题，不自动锁定原因；群体比例需要时期和口径；危机任命不自动证明每次都在找替罪者；私下交易不能靠情节合理性确认。拍卡同时写“希望观众怎样想”和“凭什么可以这样想”。
