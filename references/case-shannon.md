# 香农篇：正向创作的判断经验

## 案例身份与用法

这是路线研定、承重材料核查与节拍初排的编辑经验，不含私人原稿和聊天记录。案例形成了认可路线与28拍待讨论初版，尚不能声称已经经过完整正文、成片和观众反馈验证。八站、28拍、人物入口都是本项目选择，不是通用标准。

按当前卡点选读下面一例，不要求每次重做人物研究。这里的技术内容用来解释结构判断，后续用于新正文时仍要核原始来源和表达条件。

## 1. 从功绩清单改成理解推进

原骨架：名字开场 → 成长 → 开关电路 → 战争 → 信息论 → 下棋 → 达特茅斯 → 回到名字。

问题不在顺叙本身，而在观众可能只记住“他后来又做了一件事”。每项成果缺少出现理由，全片容易像几堂独立课程。

暂定全片问题：一个研究通信的人，为什么值得进入机器智能的历史？名字和当代产品可以引起兴趣，但命名传闻不能承担整片答案。内容应交付各项工作实际解决什么、没有解决什么。

修订后的八站分工：

|站|内容任务|交付与连接|
|---|---|---|
|R01 当下入口|建立观众熟悉的产品与陌生研究者之间的问题|承诺解释具体关系，不先罗列全部贡献|
|R02 开关与逻辑|用可见例子展示条件怎样对应电路、怎样分析与化简|把抽象逻辑变成可操作方法；成长背景按用途嵌入|
|R03 战时工作|让人物进入真实任务环境，用保密例子区分信号与情报|收到信号不一定获得新情报，同时保留人物行动与合作|
|R04 消息与概率|区分内容意义和统计度量，观察不同统计条件下的文字|理解消息可以作为概率对象研究，不急着跳到现代AI|
|R05 度量能解决什么|从表示成本走向压缩，再处理噪声、冗余、速率与界限|交付实际作用与条件，避免只记住熵和比特|
|R06 机器选择行动|用棋局展开合法走法、搜索规模、有限搜索与评价；迷宫鼠另提供探索与记忆|会执行规则还没有回答怎样选好行动|
|R07 进入AI研究计划|看具体研究计划而不只展示署名|给前面机器任务以历史位置，不把署名当充分解释|
|R08 回答开头|回收已讲清的贡献与边界|不用命名传闻反向证明动机，也不把早期工作说成现代大模型|

修改理由：成长无需独立占站；信息论需要“对象”和“作用”两层交付；AI历史定位需要具体研究内容。材料有真实联系时讲联系，没有单线因果就保留差别。

迁移边界：不是所有人物片都需要当代产品入口，不是所有章节必须接成前项发明后项。

## 2. 信息论：从定义走到结果

薄弱方案：信息能量出来 → 英文有统计规律 → 生成像英文的文字 → 联系现代语言模型。

问题：现代联系很吸引人，却可能把信息论缩成AI预告；观众听懂对象，还没获得理论实际能做什么。

可展开的理解步骤：

|拍前认识|材料或动作|新增认识|
|---|---|---|
|信息就是长短、重要或有用|比较不同可预测程度的消息，限定通信研究任务|可以研究不确定性，暂不评价内容价值|
|符号种类固定，信息就固定|保持种类不变、改变概率|概率结构影响平均信息量|
|编号都应一样长|设计符合编码条件的长短码并比较平均长度|常见结果短码可能节省平均表示成本|
|压得越短越好|加入会出错的信道|表示成本与抗错是不同任务|
|多发几遍就解决了|比较可靠性改善与占用传输机会|速率、可靠性和条件需要一起考虑|
|理论说能做到就等于已造出|交代理论界限与工程实现的距离|知道理论给出什么，也知道没有交付什么|

这是一组可展开步骤，不规定必须六拍。教学例子另核前提、码的可解码性和计算；不能把压缩与抗错冗余讲成互相矛盾。

英文统计近似可帮助观察结构，也可有限联系后续预测思想；“都预测符号”不足以证明早期方法等于现代大模型。

## 3. 下棋：让新困难真的发生

知识点清单“规则、搜索、评价”不能直接成为三拍。更可写的动作是：

给出合法走法 → 让观众尝试只看一步 → 加入对手应对 → 展示分支增加 → 尝试全算并遇规模限制 → 引入有限搜索与局面评价。

它的推进来自尝试、约束和改进，不需要虚构反派或夸大情绪。完整演示要有结果，不能只说“计算量很大”。具体棋局、数字和算法需另核，不能把任意例子归为原论文演示。

## 4. 迷宫鼠：第二个案例增加什么

若只介绍“还造了一只会走迷宫的机器鼠”，它可能重复下棋的“机器很聪明”。

有用的分工是保留行为变化：第一次探索 → 第二次利用已有记忆 → 改变环境后旧经验失效、重新探索。

这样它补充记忆、探索和环境变化，不只是第二项成就。装置机制与适应范围需要按资料限定，不能因为行为像学习就写成具有现代学习系统的能力。

## 5. 核查不能反过来支配创作意图

路线已认可后，研究任务是查到足以判断的资料。原文难取不是删站理由。证据确实不符时，列出原说法、原文支持范围、受影响位置与方案，再讨论。

例如古今联系证据薄弱，可先限定比较维度；不必因此丢掉已经成立的信息论解释链。反过来，也不能因路线认可就隐藏反例。

## 6. 从排拍到写作现场

先按内容排，形成28拍初版；把仅提醒边界、宣布下一章的内容并入相邻拍。接着应讨论全片推进、密度与时长，而非把拍数固定成目标。

研究、路线、节拍可保留，正文可以空白重新写。分开“换架构”“建独立库”“归档旧项目”“重新写正文”四种动作，按用户要求分别处理。进入工作台后逐拍试写，以正文检验拍卡，而非继续无限细化表格。
