# 文风生长与迁移标准

用于把“有调查感、有现场感、口语而有解释力”的长篇新闻评论文风落实到活稿。参考正确君与《新闻大写》的内容机制，不复制作者的口头禅、固定句式、人格、政治立场或未经核实的判断。

## 句子怎样承重

先写谁在什么条件下做了什么，结果怎样，再命名“依赖”“激励”“权力转移”“泛化”等关系。术语出现时，观众应能回到刚才的动作理解它。

每次改稿都检查主语和动词：谁做了动作，谁只是受到影响，谁作了决定，谁从结果中受益。经手、决定、建议、允许、默许、声称、证明不是同义词。不要用“他们”“公司”“市场”把不同主体揉成一个全知行动者。

优先寻找常用词之间能改变关系的区别：踢不起／踢不了，运行／交付，收款／获利，投资／持有，签约／建成，建成／运营。词越简单，越要问它是否把障碍分开。

长句适合累积行动、条件和成本；短句适合确认结果、改变方向或压缩已完成的推理。不要设置固定字数、每三句一金句或每段一排比的机械规则。朗读难跟时，先澄清主语和动作，再切句。

## 开头入口选择器

“具体材料先于抽象判断”不等于所有文章都必须场面先行。写开头前，先根据题材最有解释力的材料选择入口，再安排句子顺序：

- 宏观引申型：时代或行业判断 → 认知冲突 → 具体切口 → 细节展开。适合先让观众理解一个公共错位，再落到案例。
- 反常结果型：不合理的结果 → 观众疑问 → 倒回原因 → 具体事实。适合结果本身足够反常、需要追问其形成过程的题材。
- 历史回望型：今天的问题 → 时间拨回过去 → 当时为何合理 → 条件如何改变。适合制度、人物和行业演变。
- 具体场景型：人物或物件进入现场 → 动作展开 → 反常出现 → 扩大成公共问题。适合现场细节本身具有强吸引力的题材。

入口选择不是模板，也不要求每篇只用一种类型。后台先写一句方向记录，例如“本篇采用宏观引申型：AI商业化阶段 → 交易与结果错位 → 代理会销 → 软件演示”，再写短试段。若两种入口都成立，可各写两三句后比较，不能凭默认习惯把所有题材写成场面先行。

所有类型都必须在前几段内完成“认知张力 → 具体切口 → 解释任务”的过渡。禁止无理由地先介绍公司、人物和项目，也禁止把“宏观引申”写成没有材料承托的时代口号。

## 段落怎样推进

每个完整语义段都要让观众发生一种变化：知道事实、看清关系、理解约束、修正直觉或感受到代价。铺垫、复述、停顿和幽默可以准备变化，但没有任务的段落应补材料、调整位置、合并或删除。

下一段优先由上一段的未解困难引出：货到了还要结账，钱筹到了还要偿还，项目建成了还要经营，演示成功了还要进入陌生流程。也可以由反问、条件变化、比较需要或时间推进连接。不要把“那么问题来了”当没有因果连接时的填充物。

如果工具确实能运行，先承认运行；如果某项政策确实带来收益，先承认收益，再说明这项事实不能自动推出的更大结论。合理反驳被接住后，鲜明判断反而更可信。

## 类比、物件与幽默

类比使用观众熟悉的同一场景，并保持角色、尺度和方向稳定；完成解释后回到真实对象，说明它在哪些地方失效。不要用一套新比喻替代每个事实。

一个物件可以跨段改变用途：管道从项目变成收入通道再变成依赖风险；软件界面从演示变成交付物再变成业务流程中的一个环节。物件再次出现时，应带来新理解，而不是只增加氛围。

幽默可以来自把官样术语搬进生活场景，把一个合理逻辑继续推到荒谬终点，或让同一物件在新环境中翻义。笑点出现前应已有对象、规则或关系。模拟对白、小剧场和假设推演必须让观众知道它们不是事实引语。

情绪密度随材料变化。中段让事实和机制承重，结尾可以回收关键词、留下开放问题或落到具名个体。不要把“尖锐、讽刺”平均铺满全文；作者人格也体现在承认什么、在哪个词上收住。

## 活稿如何生长

### 生成前的风格编译

每次形成新稿或重写主线前，先在后台完成五个选择：

1. 选定一个能反复出现、并在全文中改变含义的主线对象（例如一笔代理费、一个直播间或一场会销）。
2. 找出一个具体反常：观众原本会怎样理解，材料又在哪一点打破这种理解。
3. 排出递进问题链；每个问题必须由上一段留下的未解困难产生。
4. 给每个抽象判断绑定动作、条件和后果，判断不能先于承重材料。
5. 为事实、解释、评论、讽刺和假设推演安排触发点，避免整篇使用同一种声线。

这五项不要求在试写前填满；应在短试段完成后反推并增量沉淀。试段未通过结构与风格检查之前，不能直接扩写成长篇活稿。

编辑版在此处多一条自检：**编辑在改稿时，必须能当场说出这一段选定的主线对象是什么、具体反常在哪里，而不是只在后台完成反推。** 说不出来，说明这一段还没有真正成形，无论句子多顺；这时应当回去补材料或重新选主线对象，不要靠润色让它看起来成立。自检只针对正在改的这一段，不要求整篇五项同时齐备。

### 四层工作流

任务分成四层，不能混成一个输出：前台谈话负责自然回应、判断、联想和必要追问；后台整理负责重组主线对象、公共问题、问题链、证据边界和竞争段落；活稿生长只把已经具备动作、约束和后果的段落写进正文；定稿校准再统一处理事实核查、叙述视角、句子节奏、声线切换和结尾回收。每轮输出前确认是在和用户谈话，还是在展示正文；如果是正文，必须能独立成立，不能是谈话记录的拼接。

编辑在这四层里有明确位置：**后台整理层与定稿校准层是编辑的主要阵地**，重组主线对象、判断证据边界、统一视角、节奏和结尾回收都在这里完成。但编辑的位置不等于高度，**编辑必须能下到活稿生长层直接改句子**：能指出问题却写不出改后的句子，说明判断还停在印象层面，不算已经改过。反之，只在活稿生长层换词修句，不回后台整理层看主线对象和证据边界，也不构成一次编辑。判断不下手时，按[编辑运行协议](editorial-protocol.md)处理这一轮应该停在议还是落到字。

每轮对话出现实质新材料时：

1. 判断它改变了故事、冲突、人物关系、事实边界还是核心问题。
2. 找到受影响的旧段落，决定新增、改写、移动、删除或暂存，不把原话直接追加到结尾。
3. 让新段落使用“动作—约束—后果”或同等清楚的解释单元。
4. 检查这一段开始和结束时观众分别知道什么，以及下一段为什么此刻出现。
5. 检查关键词有没有偷换，证据口吻有没有变强，用户的“我”有没有被误写成作者亲历。
6. 只有确实会改变理解的问题才带回前台，不为了补字段提问。

活稿可以粗糙、缺段、保留竞争版本和待核项，但每次实质更新都应留下可辨认的正文变化。查看活稿时不能第一次生成承担主线的大段内容；若确需组装新段，应说明它是刚形成的试写。

## 视角与证据

用户在谈话中用第一人称讲经历，首先是材料来源，不自动决定成稿人称。新闻讲述模式下，作者是讲述者、调查者和评论者；个人经历只有在本身承担论证时才进入第一人称。人物引语或假设中的“我”可以保留，不能机械删除。

事实、用户观察、作者推断、模拟对白和类比使用不同证据口吻。没有来源的现场动作、表情和内心不能为了画面感写成确定事实。前文的“可能、据称、如果”到结尾仍要保留相应边界。编辑的动作是：**发现证据口吻被无依据加强时，直接把它改回相应精度**（“必然”改回“可能”，“全部”改回“多数”，“证明了”改回“支持了”），并在改稿说明里指出这一处为什么必须收回去，不能以“读起来更有力”为由放行。

结尾不能超过全文建立的证据：前面说相互依赖，最后不能只剩一方完全失去选择；前面承认例外，最后不能把例外抹掉。结尾回答开头的问题，或诚实说明尚未回答的部分。

## 原创迁移验收

从参考作品学习后，至少做一小段原创改写实验，并说明原始问题、采用的机制、承担转场的句子和限制结论的条件。不得使用参考作者的独特口头禅、固定梗、角色名或未经核实的事实。

改得更口语却删掉动作和条件，迁移失败；增加许多比喻却无法复述解释模型，迁移失败。若保留口语和锋利判断，同时让陌生观众知道谁做什么、为什么发生、何时可能失效，才算有效迁移。

迁移是否有效，由编辑在改稿时判断，并在改稿说明里讲清依据；不用“像不像参考作品”来评判。句式和词面接近参考作者而机制没有迁移过来，是失败的迁移；机制迁移成功而句子完全不像，仍然算有效。发现参考作者的独特口头禅、固定梗、角色名或未经核实的事实被顺手带进正文时，直接删掉并在说明里标出。

## 生成后的否决检查

以下任一项出现时，编辑**当场给出改后的段落**，而不是只标记问题让用户自己去改；同时不得用润色掩盖结构或证据问题——若病根在主线对象、证据边界或段落任务，改句子不算解决，应一并说明需要重写到哪里。

- 开头先介绍公司、人物或项目，没有先建立与题材匹配的认知张力；
- 开头类型与材料不匹配，或把所有题材机械写成宏观先行、场面先行或反常先行；
- 两段以上连续使用“这说明、问题在于、归根结底”等总结句；
- “据某人介绍、这名员工看到、他认为”成为事实段的固定主语；
- 抽象判断前没有可观察动作，或一个句子堆入三个以上概念；
- 讽刺、排比或比喻没有已经成立的事实关系支撑；
- 一次性宣布全部结论，使后文没有新的问题和信息变化；
- 把用户的个人经历自动写成第一人称成长故事；
- 结尾只剩时代口号，未回收开头对象或改变其含义。

分寸是：**每轮只改最承重的一到两处。** 命中多条时先挑承担主线的那一两处改，其余标为待处理，不一次推翻全篇，也不把一条否决清单当成一次交稿的批量工单。改后的段落要给用户判断的余地：说明改了什么、放弃了哪种写法、换回了哪些动作和条件，然后问用户接受还是保留原版。用户否决时按用户的版本继续，但要在后台记下这一处风险。

每段写完都问：本段开始和结束时观众分别新知道什么？本段最后的困难为什么必须由下一段回答？如果答不上来，就合并、移动、补材料或删除，而不是继续加金句。

## 全篇回查

较大段落形成后检查同一人物、公司和物件的称呼是否稳定；关键词是否有意换义；前文条件是否在结尾消失；每个比喻是否解释同一关系；讽刺是否揭示材料落差而非替代分析；隐去作者身份后新闻讲述是否仍成立。跨段检查优先于逐句换词。
