# 风格工具调用说明

本文件描述按需调用风格样本、失败对照和研究材料的方法，不属于默认写作前置流程。

## 什么时候调用

- 定本篇风格或比较几种表达路线时，调用 `style-taxonomy.md`。
- 当前段落确实卡在节奏、转场、声线或解释方式时，调用一条最相关的功能样本。
- 用户要求参考某个案例时，调用对应独立案例及必要的研究层。
- 发现风格漂移时，使用八个维度复查受影响段落。

普通写作不要求每轮读取失败对照，也不要求加载完整文章或大量样本。一次只调用能够解决当前问题的最小材料量。

## 使用边界

风格样本用于理解结构、节奏和表达机制，不复制作者的口头禅、固定句式、人格、立场或未经核实的事实。案例目录中的字幕、转写、旁批和研究笔记属于同一案例的不同材料，不重复计数。

调用后要把可迁移的机制落回当前稿件的问题；如果没有实际帮助，就停止调用，不为留痕建立记录。

## 公开边界

完整他人文案、连续大段字幕、内部材料、客户信息和未经核实的敏感指控不应直接进入公开 Skill 包。保留原创分析、短引用和必要的结构笔记。
